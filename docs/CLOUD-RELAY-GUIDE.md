# 云盘中转同步指南（挂载网关方案）

没有 NAS？两台电脑不在同一网络？**云盘中转方案**让你用任意网盘（联通云盘/夸克/阿里云盘/百度网盘/天翼云盘等）替代 NAS 作为同步中转站——通过挂载网关工具把网盘映射为本地盘符，同步脚本无需任何架构改动即可工作。

> 适用场景：办公网与家庭网不互通、没有 NAS、或不想暴露 SMB 端口到公网的用户。
> 代价：速度受网盘 API 限制、文件修改时间（mtime）可能失真（详见下文"已知限制"）。

## 方案架构

```
┌──────────────┐                          ┌──────────────┐
│  办公机 PC-A │                          │  家用机 PC-B │
│              │                          │              │
│  sync-cloud  │                          │  sync-cloud  │
│  .bat        │                          │  .bat        │
│      │       │                          │      │       │
│  Z:\ 盘符    │                          │  Z:\ 盘符    │
│  (RaiDrive)  │                          │  (RaiDrive)  │
└──────┬───────┘                          └──────┬───────┘
       │            公网各自访问                  │
       ▼                                         ▼
   ┌─────────────────────────────────────────────┐
   │   OpenList（网关，部署在其中一台 NAS/服务器   │
   │   或两台电脑各自本地部署）                     │
   │        │  对外提供 WebDAV                     │
   │        ▼                                     │
   │   云盘（联通/夸克/阿里/百度/天翼…同一账号）    │
   │   /workbuddy-relay/ 同步中转目录              │
   └─────────────────────────────────────────────┘
```

**链路**：`同步脚本 → 本地盘符 Z: → RaiDrive(WebDAV) → OpenList → 云盘 API`。两台电脑之间零直连——云盘本身就是"会合点"。

## 第一部分：挂载云盘为本地盘符

以联通云盘 + OpenList + RaiDrive 为例（其他网盘只需换 OpenList 里的驱动选择）。

### 1.1 工具选型

| 工具 | 作用 | 说明 |
|---|---|---|
| [OpenList](https://github.com/OpenListTeam/OpenList) | 接入各家网盘，对外提供 WebDAV | AList 的社区分支（AGPL 开源）；AList 已商业易主，新装建议直接选 OpenList |
| RaiDrive | 把 WebDAV 映射为 Windows 盘符 | 免费版即够用（8 个盘符限额） |

> 替代方案：[CloudDrive2](https://www.clouddrive2.com/)（闭源，一步到位提供盘符挂载，免去 RaiDrive 层）也可用，本指南以开源组合为主线。

### 1.2 安装 OpenList 并接入网盘

**方式一：桌面客户端（新手推荐）**

1. 下载 `OpenList-Desktop_x.x.x_x64-setup.exe`，安装到非系统盘；
2. 打开客户端，开启 OpenList 服务并放行端口；
3. 点客户端里的"网页"按钮打开 `http://localhost:5244`，用 `admin` + 客户端显示的密码登录；
4. 需要开机自启时在客户端设置中打开。

**方式二：服务端版（适合部署在 NAS/常开机器上）**

1. 下载 `openlist-windows-amd64.zip`（或 Linux/Docker 版），解压到**不含中文**的路径；
2. 命令行设置密码并启动：
   ```bat
   openlist.exe admin set 你的密码
   openlist.exe server
   ```
   看到 `start HTTP server @ 0.0.0.0:5244` 即成功；
3. 浏览器访问 `http://localhost:5244` 登录。

> ⚠️ 端口冲突：若曾装过 AList 或其他服务占用 5244，OpenList 启动会失败——释放端口或改用其他端口（RaiDrive 侧同步修改）。

**添加联通云盘存储（其他网盘同理，在"存储 → 添加"里选对应驱动）**：

| 字段 | 填写内容 |
|---|---|
| 驱动 | 联通云盘 |
| 刷新令牌 / 访问令牌 | 用官方令牌工具获取（见下） |
| 根文件夹 ID | 个人云填 `0` |
| Family ID | 个人云留空 |

**获取联通云盘令牌**（其他网盘一般扫码/cookie 授权，无需此步）：

- 工具地址：`https://alistgo.com/tool/wopan/token.html`
- 推荐用**账号密码 + 短信验证码**方式登录（扫码有时不返回 refresh_token）；
- 令牌只显示一次，获取后立即复制保存；
- ⚠️ **顺序很重要**：先在 OpenList 删除旧存储 → 再取新令牌 → 立刻回 OpenList 保存 → 保存成功后才碰网页端。先取令牌再登录网页端会把 OpenList 的会话踢下线。

> 版本要求：联通云盘驱动要求 OpenList ≥ 3.19.0。保存报 `403 Forbidden` 多为令牌失效/填反/版本过低。

### 1.3 开启 WebDAV 写权限（最容易漏的一步）

OpenList 默认权限保守，**不开启则挂载后无法新建文件夹/上传**：

1. `http://localhost:5244` → **管理 → 用户 → 编辑 admin**；
2. 勾选：☑ WebDAV 读取、☑ **WebDAV 管理**（写权限关键）、☑ 创建目录或上传（如有）；
3. 保存后，断开盘符重新连接。

### 1.4 RaiDrive 映射盘符（两台电脑各做一遍）

| 项目 | 填写内容 |
|---|---|
| 类型 | WebDAV |
| 地址 | OpenList 所在机器的 IP（本机部署填 `localhost`，部署在 NAS 上填 NAS 的 IP） |
| 端口 | `5244` |
| 路径 | `/dav`（或 `/dav/你的挂载路径`） |
| 账号/密码 | OpenList 的 admin / 管理密码 |
| 盘符 | 统一选 `Z:`（两台电脑用相同盘符，配置文件可共用） |

- 确认**未勾选 Read-only**；
- OpenList 和 RaiDrive 都设为**开机自启**，盘符每次开机自动恢复。

### 1.5 排障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| OpenList 保存存储报 403 | 令牌失效/填反/版本低 | 重新取令牌；升级 ≥3.19.0 |
| 盘符里新建文件夹无权限 | WebDAV 写权限没开 / RaiDrive 只读 | 见 1.3；取消只读勾选 |
| 网页能建文件夹、盘符不能 | WebDAV 权限或 RaiDrive 问题 | 检查 1.3 和只读设置 |
| 网页也不能建 | 云盘令牌/账号问题 | 重新获取 refresh_token |
| 盘符突然打不开 | 令牌过期 | 重新取令牌并更新 OpenList 存储 |

**快速定位层级**：先在 OpenList 网页里手动新建文件夹——网页能建说明网盘接入正常（问题在 WebDAV/挂载层）；网页不能建说明令牌/账号有问题。

## 第二部分：配置云轨同步

### 2.1 建立中转目录结构

在网盘网页端手工建好（或挂载后在盘符里建）：

```
Z:\<你的云盘挂载目录>\workbuddy\
├── workspace-files\
├── projects\
├── tasks\
└── scripts\
```

### 2.2 安装脚本并配置（两台电脑各做一遍）

1. **获取脚本**（还没装过本套件的话）：仓库页面绿色 **`<> Code`** → **Download ZIP** → 解压 → 把 `scripts\` 下全部文件复制到 `%USERPROFILE%\WorkBuddy\scripts\`（详见主 README 的"第 0 步"）；
2. 复制模板为真实配置：
   ```bat
   cd %USERPROFILE%\WorkBuddy\scripts
   copy sync-config-cloud.example.txt sync-config-cloud.txt
   notepad sync-config-cloud.txt
   ```
   写入你自己的挂载路径（可以含中文——此文件由 Python 读取，不受 .bat 编码限制）：
   ```
   NAS_ROOT=Z:\联通云盘\workbuddy
   ```
3. `sync-config.txt`（NAS 轨）按需配置或保持不动——**双轨并存**，互不干扰。

### 2.3 运行

双击 `sync-cloud.bat`。首次运行会把本地全部待同步文件推上云盘（几千个小文件约需 0.5~2 小时，取决于网盘速度）；另一台电脑随后运行则只拉取差异部分——两边内容一致的文件会**哈希比对后直接跳过（零传输）**。

### 2.4 双轨并存说明

本套件支持 **NAS 轨与云轨并行**（`sync-nas.bat` / `sync-cloud.bat`），设计保证：

- 两轨的状态文件、锁、墓碑表完全独立，交替运行不产生伪冲突（内容相同的文件按哈希跳过，不依赖 mtime）；
- **删除会跨轨传播**——前提是每台电脑定期把两条轨都跑一遍（本机的墓碑镜像是两轨的汇合点）；
- 云轨脚本（含全部网关韧性补丁）也会经 NAS 轨分发，两台电脑自动保持同版本。

## 第三部分：网关链的已知限制与内置对策

以下问题全部在真实环境（联通云盘 + OpenList + RaiDrive）实测踩坑验证，脚本已内置自动处理，**你不需要做任何事**，但了解它们有助于解读日志：

| # | 网关特性 | 脚本内置对策 |
|---|---|---|
| 1 | **空文件上传被拒**（0 字节报"找不到元素"） | "写 1 字节→截断为 0"舞步，云端持久化为 0 字节 |
| 2 | 深层子目录创建有异步延迟 | 逐级建目录 + 数据与元数据分离写入 + 自动重试 |
| 3 | **正在使用的文件同步会失败甚至危险**（活跃会话对话文件被 WorkBuddy 持续追加） | 热文件守卫：2 分钟内修改过的文件本轮跳过，闲置后自然同步 |
| 4 | 云盘偶发"幽灵目录"（索引异常） | 失败隔离：单个文件失败不中断整轮，下轮自动重试 |
| 5 | **SQLite 数据库不能放在网关盘上**（锁语义不支持） | 会话规范库本地 staging：下载到本地完成全部事务，结束后整文件回传 |
| 6 | mtime（修改时间）经网关后可能失真（云端记为上传时刻） | 同步判定全部基于内容哈希而非 mtime；仅并发冲突的方向选择可能受影响——遵守使用纪律即可，输方有 .conflict 备份 |

### 使用纪律（云轨专属）

1. 离开电脑前：跑完 `sync-cloud.bat` 后**等网关上传队列清空再关机**（RaiDrive 写盘符是异步上传）；
2. 切换到另一台后：**先等几秒/刷新一下盘符目录**再跑同步（挂载层目录缓存有短暂延迟）；
3. 别两台同时写同一个会话（原有纪律，双轨不变）。

## 第四部分：网盘选型参考

| 网盘 | 评价 |
|---|---|
| 阿里云盘 | API 相对温和，优先实测 |
| 夸克网盘 | 风控趋严，次选 |
| 联通云盘 | 实测可用（本指南验证环境），免费空间够用 |
| 115 网盘 | 谨慎——风控严格（有 403 防盗链/转存机制实证） |
| 百度网盘 | 可用但非会员限速明显 |
| 天翼云盘 | 相对宽松，速度一般 |

中转目录里只有文本/小文件（对话、任务、记忆、脚本），单文件最大几 MB——**限速不是主要矛盾，API 限频和风控才是**。每次同步约比对 2000~3000 个文件的元数据，挂载层的目录缓存会大幅减少实际 API 调用。

## 常见问题

**Q：为什么不用网盘官方的"同步文件夹"功能（如微云同步助手）？**
A：那类方案是"每机一个副本、云端异步传播"，并发锁完全失效，且数据库文件有损坏风险。挂载网关方案让两台电脑经同一网关读写云端同一份，语义上接近 NAS 的"实时共享存储"，现有套件（加性合并/墓碑/冲突备份）零架构改动复用。

**Q：CloudDrive2 和 OpenList+RaiDrive 怎么选？**
A：CloudDrive2 一步到位（自带盘符挂载、完整文件系统语义），闭源、基础免费（2 云盘+1 挂载点，本方案够用）；OpenList+RaiDrive 全开源、链路多一层、排障面大一点。两者本套件都支持（都是盘符挂载形态）。

**Q：能把 OpenList 部署在 VPS 上让两台电脑远程连吗？**
A：可以（语义最像"虚拟 NAS"），但引入 VPS 成本与公网暴露面，且 OpenList 掌管全部网盘凭据，安全责任更重。家用场景推荐部署在局域网内常开设备（NAS/软路由/小主机）上，两台电脑经局域网/VPN 访问。

**Q：.bat 文件里为什么不能写中文路径？**
A：cmd.exe 的批处理解析器对 UTF-8 多字节字符有解析缺陷（即使 chcp 65001），中文会把后续命令拦腰截断成乱码碎片。所以本套件的 .bat 全部纯 ASCII，中文路径统一放在 `sync-config-cloud.txt`（由 Python 读取，无此问题）。
