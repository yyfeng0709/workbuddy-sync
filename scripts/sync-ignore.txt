# sync-ignore.txt - WorkBuddy 同步排除清单（类似 .gitignore）
# 位置：scripts/ 目录，随同步脚本一起分发，两台电脑共享这一份。
# 语法：
#   - 相对 workspace-files 根的路径，正斜杠，大小写不敏感
#   - 支持 * ? 通配符（匹配任意工作区内路径）
#   - 行尾 / 表示整个目录（含其下所有内容）
#   - # 开头为注释
# 效果：被匹配的文件不推送、不拉取、不参与冲突比对（各机本地保留自己的版本）
#
# 示例：按你自己的需要添加。常见场景：
#   <工作区目录名>/venv/                 # 虚拟环境（脚本已内置跳过，双保险）
#   <工作区目录名>/任务产物目录/          # 某任务在本机生成、无需跨机的产物
#   <工作区目录名>/key.cache              # 设备级密钥（两机不同，同步互覆会坏解密）
#   <工作区目录名>/某任务生成的报告.html   # 每机各生成一份的页面
#   <工作区目录名>/已删除任务目录/         # 清理已删任务残留时防止回拉

# ==== 通用规则（建议保留）====
*.conflict-*

# ==== 个人排除项（替换成你自己的）====
# 2026-XX-XX-XX-XX-XX/my-task/decrypted/
# 2026-XX-XX-XX-XX-XX/my-task/key.cache
